# TeleSphere — плагины и темы для Telegram

Красивый сайт-каталог на чёрном фоне с анимированным космическим фоном (звёзды, туманности, планеты, метеоры — все на канвасе).

## Возможности

- Анимированный космический фон на Canvas (звёзды с параллаксом, туманности, планеты с кольцами, падающие метеоры)
- Каталог плагинов с фильтрацией по категориям (табы)
- Каталог тем оформления (тёмные / светлые)
- Кнопки «Скопировать установку» с уведомлением
- Карточки со свечением, следующем за курсором
- Анимация появления блоков при прокрутке
- Полностью адаптивная вёрстка (десктоп / планшет / телефон)
- Мобильное меню, FAQ-аккордеон, поддержка prefers-reduced-motion

## Запуск

Откройте `index.html` в браузере — сайт полностью автономный, без внешних зависимостей и сервера.
